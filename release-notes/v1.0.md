# ConnectMate 1.0

ConnectMate 1.0 首次发布，提供完整的 App Store Connect 批量管理桌面体验。

## 本版本包含

- API Key 配置、连通性验证与多账号切换
- 我的 App 与构建版本管理（含批量标记构建过期）
- 证书、描述文件、设备与标识符管理
- 命令日志、缓存管理、导出与偏好设置
- 简体中文、繁体中文、英文界面
- 主题切换、快捷键、Sparkle 更新接入

## 发布说明

- 安装包已完成 Developer ID 签名、公证与 stapler
- 最低支持 macOS 13
- 首次使用前请确保本机已安装 asc CLI，并准备好 App Store Connect API Key
